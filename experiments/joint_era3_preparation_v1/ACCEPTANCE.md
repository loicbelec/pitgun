   continuity checks pass. All finish with ≥5kg reserve. Failed trajectories
   remain evidence and block candidate qualification; never invent finish times
   or silently remove fuel failures. Current unchanged native API reports an
   error string, so this campaign makes no typed-DNF classification claim.
2. Both old-case data and all18 fresh repeats match exactly.
3. At each common anchor: best sampled free reference median rank≤5;
   shortcut does not win all12; free reference is faster than shortcut in≥2
   contexts. This compares sampled preparations, not all player possibilities.
4. Actual exit prepared reference median rank≤5 and at least one win. Entry
   V8 is reported without requiring wins against the upgraded field.
5. Three-stop witness must not beat its one-stop baseline on all12 contexts.
   Individual three-stop wins are recorded, not hidden or prohibited.

PASS permits freezing an **experimental** field candidate. REFINE distinguishes
numerical/reserve failures from preparation-coverage/balance failures. No
retuning mid-campaign; any next matrix gets a new version/cache namespace.
Driver ordering is descriptive, not an enforced podium distribution. Candidate
coverage is deliberately bounded; neither PASS nor REFINE proves a global optimum.
